# Personal Portfolio Website

Hi! I'm Rohan Kakde (rootvector), a Computer Science student and the person behind **RootVector**.

This is my personal portfolio website, created using HTML and CSS. It introduces me, shows the skills I'm learning, and shares some of my projects and cybersecurity interests.

## About the Project

I created this personal portfolio website as part of my **HTML and CSS internship**. The main purpose of this project was to apply what I learned about HTML5 and CSS3 by building a simple, responsive website.

The website introduces me, shows the skills I'm learning, and includes my projects and contact information.

I used a dark background with red highlights to match my RootVector theme. This project also helped me practise page structure, styling, navigation links, and responsive design.

## Features

- Home section with my introduction
- About Me section with my interests and career goal
- Skills section showing the technologies I'm learning
- Projects section with descriptions and useful links
- Contact section with my email and online profiles
- Responsive layout for desktop, tablet, and mobile screens
- Simple navigation links to move between sections

## Technologies Used

- **HTML5** — to create the structure of the website
- **CSS3** — to style the website and make it responsive

No JavaScript or CSS frameworks are required.

## Getting Started

You can run this project on your computer by following these steps.

1. Clone the repository:

   ```bash
   git clone https://github.com/rootvector/Personal-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Personal-Portfolio
   ```

3. Open `index.html` in your web browser.

That's it! You don't need to install any additional packages.
